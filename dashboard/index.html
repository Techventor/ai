What the flags mean, and what this cannot see
suspect-stars
Over 5,000 stars but fewer than one fork per hundred. Real projects attract forks; langchain runs about 0.10 and pytorch about 0.27, while bought stars sit below 0.01. The score is cut by 45%.
solo-project
Thousands of stars but two contributors or fewer. Not a fault, but not community influence either.
no-license
No licence file, so nobody can legally depend on it.
issue-backlog
Open issues above 8% of stars.
too-new
Created less than three weeks ago; too early to judge.
not-software
Awesome-lists, courses and roadmaps. Excluded from the rankings — they win on stars without being software.
Missing signals
Contributor counts and 90-day commit activity need per-repository API calls, which were blocked where this scan ran, so community breadth falls back to fork count. A run with an ordinary token fills both in.
Not measured at all
Dependent counts are the strongest influence signal GitHub has, but no REST endpoint exposes them. Package-manager download figures would be the better substitute.
